What does this comparison show?+

A response is one full revision

Each step asks the model for a complete answer. It is not an individual token or an uninterrupted hidden thought. Both arms use the same observed prefix.

Two different stopping rules

The learned policy compares estimated next correctness with current correctness and a 0.05 response cost. The heuristic uses reported confidence and answer stability. Both have a two-response minimum and five-response limit.

A cost comparison, not a grade

No reference answer is sent to the stopping policy. Its scores are estimates; an early stop can miss a later correction. This demo does not certify correctness, optimality or accuracy preservation.

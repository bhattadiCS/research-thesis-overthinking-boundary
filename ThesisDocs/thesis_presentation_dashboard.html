The Overthinking Boundary Problem

Chain-of-Thought (CoT) reasoning models generate intermediate tokens before committing to an answer. However, continuing to think beyond the optimal point is often counterproductive. The model can corrupt an already correct answer (overthinking) or generate useless steps that pile up transaction costs.

Conversely, stopping early causes the model to miss a late self-correction (underthinking). The Overthinking Boundary is the optimal transition threshold that balances correctness probability against cumulative generation cost.

Optimal stopping time T* = inf { t ≥ 2 : μ_t ≤ 0 }

Bellman Optimal Stopping Equation

At any reasoning step $t$, the decision to continue is governed by the expected change in trajectory utility if the model generates one more step. We define this drift parameter $\mu_t$ as:

μ_t = (1 − q_t)α_t − q_tβ_t − λ

  • •q_t: Belief that the current answer candidate is correct given step telemetry.
  • •α_t: Repair Hazard (probability of correcting a wrong answer in the next step).
  • •β_t: Corruption Hazard (probability of corrupting a correct answer in the next step).
  • •λ: Step cost penalty (fixed at $0.05$).

N6: Precision Quantization Causal Isolation

Causal Question: Does quantizing model weights from bfloat16 down to 4-bit cause a physical degradation in reasoning trajectory accuracy?

Control Strategy: Previous experiments in literature were confounded by mixed hardware, different batch sizes, or model version mismatch. We held all parameters constant: same Blackwell GPU, same generation script, same prompt formatting, and same 1,500 tasks, isolating only the quantization format.

  • •bfloat16 Step 2 Correctness (q2): 0.2787 (n=1,500)
  • •4-bit Step 2 Correctness (q2): 0.1360 (n=1,500)
  • •Step-2 Correctness Gap: 14.27% ($Z = 9.79$, highly significant)

N3: Empirical Bayes Hazard Shrinkage

The Problem: Local, cell-by-cell hazard fitting suffers from severe data sparsity at late steps ($t \ge 5$). The resulting estimates ($\alpha$ and $\beta$) are unstable, causing premature stops in the tail.

The Solution: Shrink cell-specific hazard estimators toward global step-specific averages:

α_shrunk = (R_c + k*α_glob) / (N_c + k)

This simple shrinkage represents the largest single utility boost in the entire campaign: **$+593.55$ OOF expected utility**.

Visualizing the Shrinkage Leap

N4: Dynamic Difficulty Modulation

Causal Question: Can we adapt the stopping threshold online to accommodate tasks of varying difficulty within the same cell?

The Method: Add a second parameter $\gamma$ modulated by step-2 answer churn $s_{\text{early}}$:

μ_t ≤ δ_cell + γ * s_early

When the model's answer is unstable early on, the patience threshold is automatically raised, recovering **$+159.50$ expected utility** over the calibrated 1-parameter rule.

Slide 1: Theoretical optimal stopping framework

We formulate LLM chain-of-thought (CoT) trajectories as discrete stochastic processes and define stopping as an expected utility maximization task on a filtration.

μ_t = (1 − q_t)α_t − q_tβ_t − λ

  • •Expected drift μ_t: Tells the system whether continuing is expected to yield higher final utility.
  • •The stopping policy: Halts computation at step $T^* = \inf \{ t \ge 2 : \mu_t \le 0 \}$.
